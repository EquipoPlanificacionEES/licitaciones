---

## Prólogo

Toda empresa nace intentando resolver un problema.

Algunas desarrollan software. Otras venden consultoría. Otras comercializan
tecnología.

DOOIF nace con una idea diferente.

**No queremos construir más software. Queremos construir conocimiento.**

Durante años las organizaciones han acumulado millones de documentos,
informes, imágenes, contratos, correos electrónicos, procedimientos, manuales
técnicos, auditorías y bases de datos. Sin embargo, gran parte de esa
información permanece dispersa y rara vez se transforma en conocimiento útil
para quienes deben tomar decisiones.

El verdadero patrimonio de una empresa no está únicamente en sus activos
físicos ni en su infraestructura tecnológica. **Su patrimonio más valioso es
el conocimiento acumulado por las personas que la componen.**

Ese conocimiento normalmente se pierde cuando un profesional cambia de cargo,
abandona la organización o simplemente cuando la información queda almacenada
en documentos imposibles de consultar de manera eficiente.

DOOIF nace para resolver ese problema.

Nuestra misión es transformar el conocimiento experto de una organización en
una plataforma inteligente capaz de **preservar, comprender y reutilizar** ese
conocimiento para ayudar a tomar mejores decisiones.

No construimos inteligencia artificial por moda.
No construimos software porque exista una nueva tecnología.
**Construimos plataformas que resuelven problemas reales y repetitivos.**

## Nuestra filosofía

Cada empresa realiza miles de procesos diariamente.

En todos esos procesos existen personas que aplican experiencia y criterio
para decidir:

- Revisan documentos.
- Analizan imágenes.
- Evalúan informes.
- Interpretan contratos.
- Califican antecedentes.
- Detectan inconsistencias.
- Generan conclusiones.

Todas esas decisiones siguen reglas. Algunas son explícitas. Otras viven
únicamente en la experiencia de los especialistas.

**Nuestro trabajo consiste en capturar esas reglas, estructurarlas y
convertirlas en plataformas inteligentes.**

No reemplazamos al experto. **Multiplicamos su capacidad.**

Queremos que el conocimiento permanezca dentro de la organización y no dependa
exclusivamente de personas específicas.

## DOOIF Core

El corazón de la empresa es **una única plataforma tecnológica**. Sobre ella
se construyen todos los productos.

DOOIF Core incluye:

- Gestión documental.
- OCR avanzado.
- Procesamiento de imágenes.
- Bases vectoriales.
- Embeddings.
- Recuperación aumentada por generación (RAG).
- Motores especializados de inteligencia artificial.
- APIs.
- Gestión de usuarios.
- Auditoría.
- Workflow.
- Firma electrónica.
- Seguridad.
- Dashboards.
- Integraciones con sistemas externos.

Todo nuevo producto utiliza esta infraestructura. **Nunca desarrollaremos la
misma funcionalidad dos veces.** El objetivo es construir una plataforma que
se fortalezca con cada cliente y con cada nuevo proyecto.

### Arquitectura

Plataforma **cloud-native sobre AWS**, **desacoplada** y **orientada a APIs**,
organizada en tres capas más los productos que la consumen:

```
  PRODUCTOS     Sinergia │ Agentes de Voz │ Contactabilidad │ Atención Ciudadana │ Licitaciones │ …
  (caras del Core)  └──────────────────────┬────────────────────────┘
                                           │  APIs (REST / webhooks / WS)
                  ┌────────────────────────▼───────────────────────────────────┐
                  │                      DOOIF  CORE                           │
                  │                                                            │
                  │  MOTORES ESPECIALIZADOS                                    │
                  │   voz (STT→cerebro→TTS) · prospección · seguimiento        │
                  │   cotizaciones · agenda · cobros/pasarela · chat web       │
                  │   análisis documental/OCR · generación de agentes          │
                  │  ────────────────────────────────────────────────────────  │
                  │  CAPA DE CONOCIMIENTO                                      │
                  │   gestión documental · OCR · procesamiento de imágenes     │
                  │   ingesta → embeddings → base vectorial → RAG              │
                  │  ────────────────────────────────────────────────────────  │
                  │  CAPA DE PLATAFORMA (SaaS)                                 │
                  │   multi-tenant · auth/RBAC · planes · white-label          │
                  │   auditoría · workflow · firma electrónica · dashboards    │
                  │   seguridad · integraciones · métricas y costos            │
                  └────────────────────────────┬───────────────────────────────┘
                                               │
                                     AWS (cloud-native)
```

**Reglas de arquitectura.**
- Todo proveedor externo (STT, TTS, LLM, pasarela, búsqueda) entra por una
  interfaz conectable: se puede cambiar de proveedor sin tocar los motores.
- Los productos no comparten código entre sí; comparten el Core.
- Ningún motor conoce la interfaz de usuario; solo expone API.
- Todo evento relevante (llamada, cotización, pago, hallazgo) se reporta por
  webhook al sistema de origen, con su contexto de vuelta.

## Soluciones

Todas las soluciones son caras del mismo Core. Ninguna tiene motores propios.

### Sinergia (en producción)
Plataforma comercial completa para pymes, SaaS multi-tenant: prospección
automática con outreach, cotizaciones con link público branded
(aceptar/rechazar), motor de seguimiento multicanal, agenda de trabajos con
asignación de técnicos, cobros con link propio y pasarela enchufable, chat
web embebible y operación white-label por empresa, con planes de suscripción
y límites de uso.

### Agentes de Voz (en producción — fase 1)
Agentes conversacionales que contestan y hacen llamadas telefónicas reales
(GSM/Twilio; WhatsApp Calling en fase 2), con voz natural chilena
(Deepgram STT → cerebro Claude → Azure TTS es-CL). Conversan, capturan datos
y entregan transcripción + análisis estructurado al sistema de origen.
Incluye creador de agentes con IA y simulador de llamada por texto y voz.

### Contactabilidad (activo)
Plataforma de contacto masivo y gestiones: campañas de marcado automático
continuo, confirmación y captura de datos en la llamada, cierre de gestiones
con transcripción y análisis, y reporte estructurado al sistema que originó
el contacto.

### Atención Ciudadana — Municipios (en desarrollo)
Plataforma de contactabilidad para municipios: un agente que atiende a los
vecinos las 24 horas por teléfono, WhatsApp y chat web; responde consultas y
trámites con la información oficial del municipio (RAG sobre ordenanzas,
requisitos y procedimientos); deriva al departamento correcto registrando el
caso; y ejecuta campañas salientes de contacto (avisos, operativos,
encuestas, recordatorios de pago).

### Licitaciones (en construcción — este repositorio)
Inteligencia de compra pública: monitoreo continuo de portales de
licitaciones, ingesta de bases y anexos a la capa de conocimiento, match por
RAG entre los requisitos de cada licitación y las capacidades reales de la
empresa cliente, alertas de oportunidades y apoyo a la preparación de ofertas.

### Próximas
Cada proyecto de cliente que requiera una capacidad nueva define la siguiente
solución potencial. Regla para abrir un producto: el motor ya fue pagado por
un proyecto y al menos dos clientes distintos lo necesitan.

## Modelo Comercial

Tres motores de ingreso que se alimentan entre sí:

1. **Proyectos (financian el producto).** Soluciones a medida para clientes
   que pagan por resolver su problema concreto. Regla: no se acepta un
   proyecto cuyo desarrollo no deje al menos un motor o mejora reutilizable.
2. **Suscripción SaaS (recurrencia).** Productos sobre el Core vendidos por
   planes con límites de uso, trial y códigos de activación.
3. **White-label y partners (escala).** Terceros revenden los productos con
   su propia marca sobre la misma plataforma. DOOIF opera el Core; el partner
   pone la relación comercial.

**El círculo virtuoso:** un proyecto financia un motor → el motor se empaqueta
en un producto SaaS → el producto genera recurrencia y casos → los casos traen
más proyectos. Cada vuelta agranda el Core y baja el costo marginal del
siguiente cliente.

**Qué se cobra:** resultados y capacidad operativa, nunca "horas de IA" ni
licencias de tecnología. El precio se ancla al valor del conocimiento puesto
a trabajar.

## Roadmap

*(Horizontes, no fechas; las fechas las fija el equipo por trimestre.)*

**Horizonte 1 — Consolidar el Core (ahora).**
- Extraer formalmente los motores de Sinergia como servicios del Core con API
  documentada (voz, prospección, seguimiento, cotizaciones, agenda, cobros).
- Levantar la capa de conocimiento como servicio transversal: gestión
  documental, OCR, ingesta → embeddings → base vectorial → RAG disponible
  para cualquier motor.
- Completar la operación cloud en AWS (hoy hay despliegues en Render;
  migrar/estandarizar según el principio AWS).
- Numeración 600/809 (norma SUBTEL) para llamadas comerciales en producción
  en Chile; WhatsApp Calling fase 2.

**Horizonte 2 — Nuevos verticales.**
- Atención Ciudadana para municipios: primer municipio-proyecto financiando
  el vertical.
- Motor de licitaciones sobre la capa de conocimiento (este repositorio):
  monitoreo, ingesta de bases, match RAG, alertas.
- Empaquetar Contactabilidad como producto SaaS independiente sobre el Core.
- Workflow, firma electrónica y auditoría como servicios del Core.

**Horizonte 3 — Plataforma abierta y expansión regional.**
- API pública del Core para partners e integradores.
- Marketplace de agentes y motores; catálogo de capacidades.
- Operación multi-país (Chile, Perú, Colombia, México, EE. UU.) sin modificar
  la arquitectura principal.

"DOOIF convierte el conocimiento de tu organización en motores que trabajan
solos: atienden, venden, cotizan, gestionan y detectan oportunidades 24/7. No

**Un minuto.**
"Las organizaciones ya tienen su activo más valioso: saben hacer su trabajo.

contratos y en la cabeza de su gente, y solo trabaja cuando alguien está
disponible. DOOIF lo cambia: capturamos ese conocimiento en nuestra
